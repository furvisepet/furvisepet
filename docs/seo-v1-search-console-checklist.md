# Furvise V1 Search Console checklist

Use this checklist after the SEO changes are deployed to the canonical production domain.

1. Verify the production deployment is healthy and serves the expected metadata.
2. Inspect `https://www.furvise.com/` with URL Inspection.
3. Request indexing for the homepage.
4. Inspect `https://www.furvise.com/privacy` with URL Inspection.
5. Request indexing for Privacy.
6. Inspect `https://www.furvise.com/terms` with URL Inspection.
7. Request indexing for Terms of Use.
8. Submit or resubmit `https://www.furvise.com/sitemap.xml`.
9. Verify that Google's selected canonical matches the declared `https://www.furvise.com` URL for each page.
10. Monitor normal Search performance for impressions, clicks, queries, pages, and unexpected changes.
11. Monitor the Search Generative AI performance report when one becomes available. Until then, review AI-feature traffic within the normal Web Search performance reporting available in Search Console.
12. Check Page Indexing, sitemap processing, and crawl errors. Investigate blocked resources, redirect errors, duplicate canonicals, and unexpected indexed private URLs.

Do not automate indexing requests or submit unchanged sitemaps repeatedly. Search Console actions require a reviewed production deployment and the approved Furvise property.
