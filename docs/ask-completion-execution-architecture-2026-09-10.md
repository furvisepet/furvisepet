# Ask completion and execution contract

The prior production ten-question run remains 7 passes, 1 partial and 2 errors. None of these engineering checks changes those grades.

## Changes
- The final validator derives a five-dimension assessment (structure, evidence, subject/date, arithmetic, task). Complete requires evaluated passing or legitimately inapplicable checks, with structure and task explicitly passed. Assessments bind the body and evidence hashes; stored diagnostics cannot create approval authority.
- Source fallback under the shared request contract states that the complete task and any requested arithmetic remain unverified. It receives a limited assessment and missing obligations, even when safe to deliver.
- Bounded calculation expressions reference original source operands only. The server evaluates units, division, arithmetic and rounding. This supports a percentage of a sum without inventing a source operand for an intermediate result.
- Typed two-column body-mass projections can convert, sort and render exact-day table/CSV records without primary narrative generation. Independent review remains mandatory. Missing, ambiguous, truncated, future, unavailable or uncertain-correction evidence declines this optimization.
- Ten rows can carry their grounded calculation metadata: the shared parser/schema limit is 40 calculations, while existing output and evidence budgets remain bounded.
- Conversation scope is reconstructed from persisted USER turns, carrying active and compared pet sets plus a dated task. Plural reference scope no longer depends on recognizing a comparison verb. Explicit narrowing and unrelated turns reset scope; assistant text supplies no facts.
- A monotonic 45-second admission budget coordinates provider stages within the existing outer route timeout. Historical generation and repair reserve 8 seconds for review. Provider phase order is tracked independently of ordinal call numbers; the existing five-call cap remains.
- Review declines record a named diagnostic. Public errors expose only an allowlisted stage code. No source prose, exception text or stack is added to public errors.
- Admission settlement is extracted from the route and independently tested: bookkeeping failure cannot erase an already durable answer.

## Evidence and limits
The ten-pet projection integration test runs actual interpretation validation, retrieval, generation selection, independent mocked review, final validation and the persisted presentation policy. It asserts zero primary narrative calls, one independent review, complete assessment and intact CSV.
The expression test varies activity/rest operands across 100 combinations and rejects wrong output, fabricated operands, invalid dimensions and zero division. Fifteen verb/reference combinations preserve the same two-pet scope.
The full local suite passed 2,510 top-level tests before the final settlement extraction; its 42 affected tests and typecheck passed after extraction. Lint has zero errors and existing warnings. The production build passed before extraction; CI will verify the final commit.
Semantic intent and factual entailment remain model-assisted. These mechanisms do not establish universal correctness or a 95–100% production reliability claim. A 15-question live set is a regression measurement, not population-level evidence.
Primary generation timeout was an observed primary-call failure. An outer timeout killing a previously verified primary was not established. The excerpt path is a verified omission mechanism, not a proven trace-level cause for the earlier Pebble request.
