# Shared Ask release candidate — 2026-09-09

This candidate replaces serialized JSON prose with a bounded typed value tree, rendered on the server. It applies effective-plan history access (free: three calendar months; Plus: five years) to initial context, historical retrieval, episode references, and final generation. Excluded periods are an access limitation, not evidence of no records. Profiles and current owner preferences remain account context. No records are deleted and no Pro entitlement is introduced.

Named pet scopes cannot be widened by a contradictory account-scope proposal. Writer, interpretation, review and repair calls share a 45-second provider deadline within the existing request budget. Final composed answers are checked against the requested format before receiving review approval.
