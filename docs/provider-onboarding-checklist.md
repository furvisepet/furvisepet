# Authorized product provider onboarding checklist

No provider may be marked approved or used for publication until every applicable item is verified by a Furvise reviewer. Store only references and operational status in ingestion metadata. Do not commit contract documents, private agreement text, credentials, or merchant exports.

## Commercial approval

- [ ] Provider application submitted
- [ ] Provider account approved
- [ ] Merchant or brand relationship approved
- [ ] Catalog access granted
- [ ] Product-feed use permitted
- [ ] Agreement effective date recorded
- [ ] Agreement status recorded as approved
- [ ] Termination, suspension, and expiry handling documented

## Content rights

- [ ] Product-name use confirmed
- [ ] Image use confirmed
- [ ] Description use confirmed
- [ ] Price use confirmed
- [ ] Destination-link use confirmed
- [ ] Affiliate tracking confirmed
- [ ] Ingredient, warning, and direction use confirmed where supplied
- [ ] Attribution requirements documented

## Market and refresh

- [ ] Canadian market explicitly confirmed
- [ ] Currency confirmed as authoritative for the allowed country
- [ ] Availability or stock authority documented
- [ ] Refresh frequency and request limits documented
- [ ] Stale-price threshold documented
- [ ] Missing-row and discontinued-product handling documented
- [ ] Source outage behavior confirmed to preserve valid live records

## Security and validation

- [ ] Credential names match official provider documentation
- [ ] Credential storage verified as server-only and non-public
- [ ] Provider and merchant hosts allowlisted
- [ ] Catalog identifier and authorization reference recorded
- [ ] Export date and feed version/hash recorded
- [ ] Test batch completed
- [ ] Duplicate and claim review completed
- [ ] Publication review completed
- [ ] Public-response inspection confirms contract metadata is absent

Approval of an account alone is insufficient. The merchant relationship, catalog access, intended country, individual content rights, and tracking-link rights must also be active.
